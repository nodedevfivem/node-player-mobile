RELEASE TITLE:
NODE Player Mobile v0.1.1 — Playing Indicator & Song Rename

RELEASE DESCRIPTION:

🎵 NODE PLAYER MOBILE v0.1.1
The Classic Music Experience. Reimagined.

✨ WHAT'S NEW

✅ The active song is now highlighted in electric cyan in song lists.
✅ Animated three-bar "now playing" indicator rises and falls beside the active track.
✅ "NOW PLAYING" label beside the artist for easier identification.
✅ Pausing freezes the indicator and changes the label to "PAUSED".
✅ Indicators automatically follow the current song when you skip tracks.
✅ Consistent active-track indicators in Library, Home (recent songs), and Playlists.
✅ No microphone permission, internet connection, or audio analysis needed for the animation.
✅ Edit song names directly from the ⋮ menu in Home, Library or Playlists.
✅ The edited name immediately appears in the list and Now Playing screen.
✅ Custom song names survive scans and app restarts in the local database.
✅ Restore the original song title at any time.
✅ Original MP3 files and embedded metadata are never changed.
✅ Additive migration preserves existing favorites, playlists and playback history.

💿 EXISTING FEATURES PRESERVED

• Music folder scanning, custom folders, and Import Music
• Favorites, playlists, artwork, search, and sorting
• Offline playback, background media controls, shuffle and repeat
• GitHub update checks (Update Now / Maybe Later)
• Original NODE Player logo and dark cyan interface

🔒 PRIVACY
100% local music playback. No account or online database required.

📱 REQUIREMENTS
Android 10+ | App version 0.1.1 (versionCode 2)

⚠️ TEST BUILD NOTICE
The GitHub Actions APK is a DEBUG/testing APK. Each cloud run may use a different
debug signing certificate, so installing it over the previous debug APK may fail.
Do not uninstall the existing app without a backup: uninstalling can erase locally
stored favorites, playlists, preferences, and custom song names.
For public releases and reliable in-place updates, sign APKs with the same private
release keystore every time; do not share signing secrets in the repository.
